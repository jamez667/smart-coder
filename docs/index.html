smart-coder

An agentic coding tool built for small models — and a deterministic compliance evidence engine built on the same core.

Compliance evidence

This repository audits itself against ten compliance frameworks and publishes the result. It is a live demonstration rather than a claim: most of any framework is organizational and cannot be assessed from source, and the report says so control by control.

Read the evidence packs → — SOC 2, ISO 27001, NIST SSDF, SLSA, CIS v8, PCI DSS, NIST 800-53, HIPAA, GDPR, and the EU NIS2/DORA/AI Act cluster.

File paths, line numbers and evidence excerpts are withheld from the published packs. They show what was assessed and what the verdict was, not where to look.

00 — Overview, goals & non-goalssmart-coder is a terminal-based agentic coding assistant whose defining constraint is that it runs on small language models — never larger than 12B parameters, and ideally on a model as small as Gemma 4 E4B.
01 — Architecturesmart-coder is a single Rust binary that runs an agent loop in the terminal.
02 — Model backends & abstractionOne agent, many runtimes.
03 — The agent loopA small model cannot be trusted to hold a long plan, reason many steps ahead, or recover from its own mistakes.
04 — ToolsTools are how the model affects the world.
05 — Context managementA frontier model with a 200k window can absorb sloppy context.
06 — CLI & UXv1 is terminal-only.
07 — Roadmap & milestonesGoal: prove the plumbing end-to-end with the dumbest possible loop.
08 — Orchestration & the worker swarmA single tiny model is a weak agent.
