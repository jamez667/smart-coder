Scope and limitations

This pack inspects source-controlled artifacts only. CIS v8 governs an enterprise estate: endpoint inventory, account management, network infrastructure, malware defences, physical media and security awareness. None of that is visible from a repository. What this pack evidences: the software-development safeguards (Control 16), configuration-as-code (Control 4), audit logging (Control 8), data protection (Control 3), and continuous vulnerability management (Control 7) — as they appear in source. Implementation Groups (IG1/IG2/IG3) are not modelled: a safeguard's group depends on organizational size and risk, which this tool cannot know.
