We assessed the smart-coder project against 111 controls across 10 compliance frameworks using an automated source-code scan. The tool verified 42 controls as passed based on evidence found directly in the source code. There are 6 identified gaps where evidence is absent or contradicted. The remaining 63 controls are unknown, meaning they relate to organizational documentation, policies, or vendor contracts that cannot be determined from a code scan. Overall, the tool achieved a 43% determinacy rate, resulting in a 38% pass rate of the assessed controls. Zero tool errors occurred, though the command-exit-code capability was disabled for this run.

To address the outstanding gaps efficiently, we are prioritizing two high-severity items that span multiple frameworks. Implementing automated dependency vulnerability scanning for acquired components will resolve gaps across the NIST Secure Software Development Framework, PCI DSS v4.0, and NIST SP 800-53 Rev. 5. Additionally, establishing signed releases and build provenance in the release pipeline will address overlapping requirements in both the NIST Secure Software Development Framework and SLSA v1.0.

The high volume of unknown controls reflects the limits of automated code scanning rather than project failures. Frameworks heavily reliant on governance require documentary evidence outside the codebase. This is most visible in the EU regulatory cluster covering NIS2, DORA, and the AI Act, which yielded only a 20% determinacy rate because those frameworks largely consist of governance controls requiring documentary evidence.

How to read this

Determinacy is the number that matters. It is the share of in-scope controls the tool could decide either way. A low figure does not mean poor security — it means most of that framework is organizational (board oversight, vendor contracts, training records, incident procedures) and simply is not visible in source code.

Each framework's page states, in its own scope note, exactly what it cannot assess. That honesty is the point: a report claiming broad coverage of a governance framework from a code scan would be misleading.
